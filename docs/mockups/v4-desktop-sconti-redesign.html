Note di design — desktop

Stessa logica gerarchica del mobile, layout largo. Segment principale in alto a destra dell'header pagina, sub-segment sotto. Lista compatta full-width per "I miei sconti / Disponibili" con bottone "Apri QR" che apre modal centrato 480px.

Differenze vs mobile

  • Drop in griglia 3-col vs carousel
  • Convenzioni 3-col vs lista verticale
  • "I miei → Disponibili": lista full-width invece che strette
  • QR popup = modal centrato 480px (vs bottom sheet mobile)
  • Hover state sulle card

Riuso elementi esistenti

  • Sistema QR scan ristoratore già live (sposta automatico in Utilizzati)
  • Card drop = stessa estetica banner home
  • Card convenzione = simile a card live attuale
  • AuthGate di PR20b per "Prendi sconto" se anonimo

Stati DB per ogni sconto

  • NULL (nessuna riga) = disponibile (catalogo)
  • saved = preso, da usare
  • used = scansionato dal ristoratore
  • Counter "I miei sconti" = COUNT WHERE user_id=$ AND status IN ('saved','used')

Edge cases

  • Sconto scaduto in "I miei → Disponibili": badge "scaduto", bottone QR disabilitato, copy "non più valido"
  • Drop esaurito (10/10 presi) prima del salvataggio: scompare da Disponibili catalogo, non disponibile
  • Anonimo che clicca "Prendi sconto": AuthGate stesso pattern PR20b
