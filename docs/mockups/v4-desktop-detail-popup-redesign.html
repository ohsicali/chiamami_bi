Differenze desktop vs mobile

  • Modal centrato 520px (vs bottom sheet 100% width mobile)
  • Foto 16:9 (vs 4:3 mobile) — sfrutta meglio la larghezza desktop
  • Backdrop blur scuro 55% per isolare il modal dal background
  • Animazione fadeIn + scale (vs slideUp mobile)
  • ESC chiude · click su backdrop chiude · X chiude
  • Tipografia leggermente più grande (h2 30px vs 26px)
  • Stesso identico contenuto e pattern editoriale: foto + percentuale overlay + countdown (drop) + Secondo Bi + specs + Scopri ristorante + CTA

Markup riusabile

  • Stesso componente React <DiscountDetail> per mobile e desktop
  • Container responsive: bottom sheet su mobile, modal centrato su desktop (CSS-only via media query)
  • Animazione differente (slideUp vs fadeIn) gestita via CSS custom property
