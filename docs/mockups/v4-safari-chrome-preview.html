iPhone · Safari · Chiamami Bi v4

Come appare davvero la web app dentro Safari

I mockup precedenti mostravano lo schermo dell'iPhone pieno 390×844 px. In realtà Safari occupa ~52 px in alto (barra URL) e ~84 px in basso (tab bar + home indicator). Meno di due terzi dello schermo sono davvero usabili — e l'altezza utile cambia anche quando scrolli. Ecco cosa cambia.

1Il problema

Su iPhone, quando apri chiamamibi.com in Safari (non come app "Aggiungi a Home"), ci sono due barre sempre presenti:

  • Top · Status bar + URL bar Safari → ~52 px persi
  • Bottom · Tab bar Safari + home indicator → ~84 px persi
  • Totale · ~136 px sottratti a 844 = ~708 px utili

Se il layout è pensato a 844 px pieni, tutto quello che è "fissato in fondo" (nav, CTA, tastierino PIN) finisce sotto la tab bar e non si vede.

2La soluzione CSS

  • min-height: 100dvh invece di 100vh → si adatta a Safari in tempo reale
  • padding-top: env(safe-area-inset-top) → stacco dallo status bar
  • padding-bottom: env(safe-area-inset-bottom) → stacco dall'home indicator
  • viewport-fit=cover nel meta → abilita le env()
  • Nav o CTA fissi in basso → bottom: env(safe-area-inset-bottom)

Supportato iOS 15.4+ (2022). Per iOS < 15 usa 100vh come fallback.

Snippet CSS da applicare nel codice reale

Questo è quello che deve cambiare in src/ — dallo a Claude Code come PR singola prima di Track B

/* index.html — meta viewport già presente, verifica che abbia viewport-fit */
<meta name="viewport"
       content="width=device-width, initial-scale=1, viewport-fit=cover">

/* src/styles/globals.css — ovunque uso 100vh, sostituire con 100dvh */
.screen-full {
  min-height: 100vh;            /* fallback iOS < 15.4 */
  min-height: 100dvh;           /* iOS 15.4+ Safari-aware */
}

/* Root layout — padding per non andare sotto status bar e home indicator */
.app-root {
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
}

/* Nav/CTA fissi in basso (es. bottom-sheet, CTA scheda locale) */
.bottom-nav, .bottom-cta {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  padding-bottom: calc(12px + env(safe-area-inset-bottom));
}

/* Card flottanti (es. card ristorante sulla mappa) */
.floating-card {
  position: absolute;
  bottom: calc(14px + env(safe-area-inset-bottom));
}

/* Schermate che NON devono scrollare (PIN, verify, splash) */
.no-scroll-screen {
  height: 100dvh;                   /* NON 100vh */
  overflow: hidden;
  display: flex;
  flex-direction: column;
}
