✦ Scelte desktop

Layout 01

Split 480px + resto mappa

Pattern Airbnb/Booking classico per discovery geografica. Colonna sinistra fissa a 480px con filtri sticky + lista scrollabile, mappa occupa il resto. Su schermi più larghi la mappa respira, la lista resta leggibile. Nessun toggle Mappa/Lista su desktop — si vedono entrambe contemporaneamente.

Top nav floating

Header stile home · fluttuante centrato

Pattern floating pill come nella home desktop: nav non attaccato ai bordi ma centrato con max-width 1360px, backdrop blur 24px, border rounded 999px, shadow decisa + inset white. Contenuto: logo + Home/Esplora/Sconti/Salvati + search globale + city Torino + avatar corallo. Questo è lo header "signature" di Bi — da usare in tutto il sito desktop (Home, Esplora, Sconti, ecc).

Filtri

Stessi 3 pill del mobile + sort

Filtri (badge N) · Categorie · Sconti + "Azzera" inline. In aggiunta un piccolo Sort dropdown a destra del count (desktop ha lo spazio, utile per vedere: Distanza / Consigliati / Recenti). Tap filtri = stesso sheet pattern del mobile, ma qui come dropdown overlay 420px sotto la pill invece di fullscreen.

Mini-card

Stesso layout, foto 120px

Card foto+body come mobile ma foto un po' più grande (120px vs 96px). Hover: border più marcato + shadow + leggero lift. Click sulla card = centra il pin corrispondente + apre hover-card sulla mappa. Pattern "click list → highlight map" usato da Airbnb.

Mappa

Pin rotondi grandi + hover card

Pin rotondi 52px (più grandi del mobile 44px per usabilità mouse) con emoji categoria. Click su pin → apre hover-card flottante in basso-sinistra con foto + nome + meta + sconto. Click sulla card = vai alla scheda locale.

Map controls

Zoom +/− + geo FAB

Alto-destra: + / − zoom (Mapbox standard). Basso-destra: geo-FAB che centra sulla posizione utente. Niente layer/type selector (la mappa base Mapbox basta).

Coerenza

Stesse icone SVG del mobile

Tutte le icone (Filtri sliders, Categorie grid, Sconti tag, Search, Distanza sort) sono SVG Lucide-style stroke 2 identiche al mobile. Un solo pattern icon system, scala pulita a tutte le risoluzioni, editabile con CSS color.
