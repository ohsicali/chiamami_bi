NOTE FINALI ADMIN Tokens: stessi del user-facing (ink, corallo, cream, oro, green-gradient) più --line:#EAE3D7 per bordi tabelle. Una sola famiglia UI: Poppins. Zero handwriting, zero italic decorativo.
Pattern ricorrenti: KPI card (label + val + delta + spark), activity row (ic + text + time), top row (foto + nome + zona + view), table row (cover + nome + tag + disc + status + actions), drawer lateralE con save-actions in header, inbox-tile per candidature in dashboard.
Label tecniche: uppercase 10–11px, letter-spacing .14em, muted. Il modo in cui il back-of-house "parla" a Bi.
Azioni primarie: sempre corallo con shadow 0 6px 14px rgba(232,69,60,.28) — l'unica cosa brand-bright nel pannello. Tutto il resto è ink/cream/muted.
Niente recensioni, niente stelle, niente moderazione: la guida è curata, l'admin lo riflette. Al posto di "Moderazione" c'è "Segnalazioni" (errori fattuali: orari, chiusura, telefono) in Curatela.
IA: Catalogo (cosa c'è in guida) · Curatela (cosa entra/esce) · Crescita (chi usa Bi) · Numeri (come sta andando).
