Azzera filtri · 3 modi

Come si azzerano i filtri comodamente

Tre entry point per reset: (1) link "Azzera" inline a destra della riga pill (appare solo quando filtri attivi, corallo), tap singolo resetta tutto. (2) Dentro ogni pill di filtro attivo c'è un ✕ per rimuovere quello solo. (3) Nel filter sheet, bottone "Azzera filtri" outline sotto la CTA "Mostra N locali". Feedback: il count si aggiorna live mentre resetti. Tutti e 3 i pattern convivono senza conflitto.
